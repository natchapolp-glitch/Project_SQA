Behaviors/boundaries to test:

1. `className()`/`classNames()`/`hasClass()` on element with no `class` attribute — should return empty string/empty set, not throw.
2. `addClass`/`removeClass`/`toggleClass` on element with no prior class attribute — verify correct attribute creation, idempotency, and whitespace-separated token handling (dedupe, case sensitivity per hasClass).
3. `classNames(Set<String>)` setter — verify it replaces existing classes and `attr("class")` reflects new joined value; empty set should clear/remove class attribute cleanly.
4. `text()` and `html()` round-tripping through `Parser.parse` for nested block vs inline tags (`isBlock`/`preserveWhitespace` from `Tag`), e.g. `<pre>`/`<textarea>` whitespace preservation vs normal block collapsing.
5. `Tag.isBlock()` / `canContainBlock` semantics affecting parser's `stackHasValidParent`/`popStackToSuitableContainer` — e.g. inserting a block tag inside an inline-only container should relocate to valid ancestor (`defaultAncestor`), confirmed via parsed DOM structure.
6. `appendElement`/`prependElement`/`appendChild`/`prependChild` ordering and parent/child linkage correctness, including boundary of empty children list.
7. `parent()`, `parents()`, sibling navigation (`nextElementSibling`, `previousElementSibling`, `firstElementSibling`, `lastElementSibling`, `elementSiblingIndex`) on root element (no parent) — must return null/empty Elements/0 without NPE.
8. `getElementById`, `getElementsByAttributeValue*` family — case sensitivity, empty-value match, no-match returns empty Elements, not null.
9. `select()` with malformed/empty selector string — contract-defined exception type (e.g., `Selector.SelectorParseException`) vs silently empty.
10. `Parser.parseBodyFragment` vs `parse` — fragment should not auto-wrap in extra html/head when combined with existing doc structure; verify body-only content placement.
