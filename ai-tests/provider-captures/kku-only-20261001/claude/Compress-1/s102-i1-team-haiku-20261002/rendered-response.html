Test Design Rationale:

  1. Constructor tests verify initialization with different formats and validate format validation
  2. ensureOpen tests confirm the closed-state check mechanism
  3. Entry management tests verify duplicate detection, automatic time/format assignment
  4. Write tests cover bounds checking, entry overflow detection, current entry validation
  5. Format tests ensure all CPIO format variants are supported
  6. State tests verify proper transition through open → writing → closed states

All tests follow JUnit 3.8.2 conventions (extending TestCase, setUp/tearDown) and use Java 1.4 compatible syntax.
