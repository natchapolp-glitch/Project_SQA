Analysis and Test Generation for BeanPropertyWriter

I'll generate comprehensive regression tests for BeanPropertyWriter based on the production source and build configuration. The project uses JUnit 4.10 and is Java 11 compatible.

Key Observations from Source:
Immutable design: Most fields are final; copy constructors create new instances
Internal settings: HashMap-based opaque storage for extensions
Serialization flow: Three variants (field, column, placeholder)
Dynamic serializers: PropertySerializerMap for runtime type resolution
Self-reference detection: Checks cycles unless serializer uses object IDs
