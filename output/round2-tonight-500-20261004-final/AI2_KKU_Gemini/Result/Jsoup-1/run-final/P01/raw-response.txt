- Document construction requires a valid base URI string.
- `createShell` initializes standard HTML structure (html, head, body).
- `title()` returns empty string or current title text; `title(val)` sets it.
- `head()` and `body()` must return non-null structural child elements.
- `normalise()` ensures mandatory structural elements exist and are correctly ordered.
- `createElement(tag)` generates a new element bound to the document.
- `outerHtml()` serializes the complete document tree to a string.
- `text(val)` sets the text content of the document body.
- Receiver setup requires initializing a Document via constructor or `createShell`.
- Boundary conditions include empty titles, missing head/body, and malformed structures.
