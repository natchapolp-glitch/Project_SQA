1. `createNumber` must successfully parse valid integer and floating-point string representations into the correct `Number` subclass.
2. `createNumber` should throw a `ParseException` or `NumberFormatException` when given malformed or non-numeric strings.
3. `createClass` must resolve valid fully-qualified class names into their corresponding `Class` objects.
4. `createClass` should throw a `ParseException` or `ClassNotFoundException` when the class name cannot be found.
5. `createDate` must correctly parse standard date/time string formats.
6. `createURL` must convert valid URL strings into `java.net.URL` instances and reject malformed URLs.
7. `createFile` and `createFiles` must properly handle valid file path strings.
8. `createObject` must instantiate objects via reflection using fully-qualified class names.
9. `createValue(String, Object)` and `createValue(String, Class)` must delegate properly based on the target type object or class.
10. All methods are static utility methods; receiver setup requires passing valid or boundary-test strings representing the target types.
