Valid receiver setup: Initialize `XmlTokenStream` with a valid StAX `XMLStreamReader` (or `XMLStreamReader2`) instance and a source reference object.
Token iteration: Verify `next()` correctly advances through `XML_START_ELEMENT`, `XML_TEXT`, `XML_END_ELEMENT`, and `XML_END`.
Attribute handling: Test `hasAttributes()`, attribute name/value extraction, and `skipAttributes()` boundaries.
Element wrappers: Test navigation and state consistency around repeated elements and wrapped collections (`_currentWrapper`).
End element skipping: Verify `skipEndElement()` properly advances past matching end tags without losing token synchronization.
Closing behavior: Verify `close()` and `closeCompletely()` properly release underlying reader resources.
