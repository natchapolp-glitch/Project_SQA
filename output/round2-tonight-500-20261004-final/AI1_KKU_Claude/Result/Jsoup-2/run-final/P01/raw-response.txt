Behaviors/boundaries to test via `Parser.parse(String html, String baseUri)` and `parseBodyFragment`:

1. Basic well-formed HTML parses into correct DOM tree (html>head/body structure).
2. Self-closing/void tags (e.g., `<br>`, `<img>`) don't swallow subsequent siblings.
3. Unclosed tags are auto-closed at EOF or at parent boundary (e.g., `<p>1<p>2` yields two sibling `<p>` elements).
4. Mismatched/stray end tags (e.g., `</div>` with no matching open) are ignored without throwing.
5. Nested tags with improper close order correctly pop stack to nearest matching ancestor, not deeper/shallower.
6. Comments (`<!-- -->`), CDATA, and XML declarations are parsed as distinct node types, not as text/elements.
7. Attributes with single quotes, double quotes, and unquoted values parse correctly; boolean attributes preserved.
8. Text nodes preserve whitespace/entities correctly and are not merged incorrectly with sibling elements.
9. `<title>` and `<textarea>` content treated as raw text (no nested tag parsing inside them).
10. `parseBodyFragment` wraps fragment content inside `<body>` without requiring full `<html>`/`<head>` structure; empty/null input handled gracefully (empty Document, no exception).
