- `removeMapping(key, value)`: removing last value for a key should remove key's entry entirely from underlying map; removing non-existent key/value pair returns null; removing one of multiple values keeps the key with remaining collection.
- `containsValue(value)`: should search across all keys' collections, not just top-level map values (decorated map's values are Collections, not raw values).
- `containsValue(key, value)`: true only if key exists and its collection contains value; false for missing key or missing value.
- `put(key, value)`: first put for a key creates a new collection via `collectionFactory`/`createCollection`; subsequent puts append to same collection; return value semantics (should return added value, not previous collection) per MultiMap contract.
- `putAll(Map)`: each entry's value added via multimap semantics (wrapped into collection), not raw replacement; iterating source map multiple entries.
- `putAll(key, Collection)`: adding empty/null collection should be no-op returning false; adding non-empty collection returns true and merges with existing values for key.
- `values()`: aggregated view of all values across all keys' collections (flattened), total count matches `totalSize()`.
- `size(key)`: 0 for absent key; correct count for present key after multiple puts/removes.
- `getCollection(key)`: null for absent key; same collection instance reference semantics for present key.
- `iterator(key)`: iterates values for that key; empty/absent key yields empty iterator (not NPE).
- `totalSize()`: sums sizes across all keys, updates after put/remove/clear; zero after `clear()`.
- Boundary: decorate with Class vs Factory constructors—collectionFactory determines collection type (e.g., ArrayList, HashSet) returned by `createCollection(int)`.
