- Valid constructor setup: populationSize > 0, sampleSize in [0, populationSize], numberOfSuccesses in [0, populationSize]; verify getters return constructor args unchanged.
- Constructor must throw NotPositiveException for negative sampleSize/numberOfSuccesses, NotStrictlyPositiveException for populationSize<=0, NumberIsTooLargeException when sampleSize>populationSize or numberOfSuccesses>populationSize.
- getSupportLowerBound() = max(0, sampleSize+numberOfSuccesses-populationSize); getSupportUpperBound() = min(sampleSize, numberOfSuccesses); isSupportConnected() always true.
- probability(x) must be 0 outside [lowerBound, upperBound], and match hypergeometric PMF formula C(numberOfSuccesses,x)*C(populationSize-numberOfSuccesses, sampleSize-x)/C(populationSize,sampleSize) at valid x including both bounds.
- cumulativeProbability(x) should be 0 for x < lowerBound, 1 for x >= upperBound, monotonically nondecreasing, and sum of probability() over domain equals cumulativeProbability(upperBound)=1.
- upperCumulativeProbability(x) = 1 - cumulativeProbability(x-1) semantics: check consistency upperCumulativeProbability(lowerBound)=1, upperCumulativeProbability(upperBound+1)=0.
- getNumericalMean() = sampleSize*numberOfSuccesses/populationSize (exact known formula) — test against closed-form.
- getNumericalVariance() = known closed-form variance; test with small hand-computed example (e.g., populationSize=10, numberOfSuccesses=5, sampleSize=5) against exact rational value.
- Boundary case where support is a single point (lowerBound==upperBound): probability at that point should be 1.0, cumulativeProbability should be 1.0 for that x.
- Test with extreme but valid small values (populationSize=1, sampleSize=1, numberOfSuccesses=1 or 0) to check no divide-by-zero/off-by-one errors in domain computation.
