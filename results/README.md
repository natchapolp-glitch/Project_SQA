# Results and provenance

`results/raw/` contains machine-produced artefacts.  Each execution must retain
its command, revision, seed, environment information, stdout/stderr, and raw
output.  Do not replace a prior run: create a new run directory instead.

The current checked-in pilot is Defects4J `Lang-1`; it validates the tooling and
the differential-oracle workflow only.  It is not an all-project final result.
AI result folders remain empty until an authorised run supplies real tool output.
