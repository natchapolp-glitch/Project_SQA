- get(int): returns correct value for valid index, throws ArrayIndexOutOfBoundsException (or similar) for negative/out-of-range index.
- get(String name): returns correct mapped value; throws IllegalStateException if mapping is null; throws IllegalArgumentException if name not in mapping; handles mapped index out of range of values (null or exception) — check isSet/isMapped boundary.
- isMapped(String): true only if mapping non-null and contains key; false if mapping null or key absent.
- isSet(String): true only if isMapped(name) AND mapped index < values.length; false otherwise, no exception.
- isConsistent(): true if mapping is null OR mapping.size() == values.length; false otherwise.
- iterator(): iterates exactly over values array in order, supports empty values array.
- values(): returns the same (or equal) array as constructed, preserving order and length including zero-length.
- getComment(): returns comment string passed to constructor, including null.
- getRecordNumber(): returns exact long passed to constructor, including 0 and negative edge cases if allowed.
- size(): equals values.length, including zero.
- toString(): non-null, contains values' content in some deterministic form (use Arrays.toString semantics as contract).
